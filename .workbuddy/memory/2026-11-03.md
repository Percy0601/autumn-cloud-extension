## 踩坑记录（重要，复用价值高）
1. httpclient5 5.5 无 ClassicRequestBuilder（在 httpcore5 的 org.apache.hc.core5.http.io.support）；EntityUtils.toString 抛受检 ParseException
2. Boot 4 模块化：WebServerInitializedEvent 在独立构件 spring-boot-web-server；HttpHeaders 需显式依赖 spring-web
3. SC 2025.1（loadbalancer 5.0.3）：ServiceInstanceListSupplierBuilder 为独立类；RequestDataContext 移到 spring-cloud-commons
4. 沙箱环境变量 SERVER__PORT=58890 会被 Spring 宽松绑定为 server.port（冒烟时需 env -u SERVER__PORT）
5. macOS 组播两坑：① joinGroup 走 IPv6 网卡会 setsockopt 失败 → 必须选带 IPv4 的网卡；② bind 通配地址时同端口多进程只有最后 bind 的能收到 → 需 bind 组播地址本身；③ 用 bind 组播地址的 channel 发送会因源地址=组播地址被丢 → 必须独立未 bind 的发送通道
6. spring-boot-maven-plugin 的 pom mainClass 配置会覆盖 -Dspring-boot.run.main-class（多 main 类项目把 mainClass 只配在 repackage execution）
7. curl 本地测试需 --noproxy '*'（用户 Clash 代理拦截 127.0.0.1）
